# Interactive Campus Explorer (Holo Grid)

A responsive site for discovering campus clubs, events and student resources, built for the GDG Web Development pre-interview. All content is sample data, not official college information.

Idea: each club is a 3D tower (Three.js). Search and filters shrink the towers that do not match, and hovering a card grows its tower. HTML, CSS and vanilla JS only; Three.js loads from a CDN. Open index.html to run.
